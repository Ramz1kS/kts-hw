# E-Commerce для курса KTS "Начинающий разработчик"

## Реализованы:
### ДЗ 4
- Корзина с использованием LocalStorage
- Работа с данными в MobX 
- Поиск
- Фильтрация по категориям 
- Пагинация теперь использует query-параметры
- Скелетон-лоадеры
#### Дополнительно
- Исправлено большинство замечаний куратора по поводу ДЗ 3
- Отображается рейтинг товара
- Отображается наличие товара
- Фильтрация по наличию товара с помощью чекбокса
- Анимации с использованием Framer Motion

Код отформатирован с помощью Prettier :nails:

### ДЗ 3
- Страница со списком товаров с получением данных из API, фильтрация и поиск нефункциональны
- Страница товара с получением данных из API, похожие товары - просто первые три товара из запроса в API списка товаров
- Пагинация в странице со списком товаров
- Адаптивная вёртска
- Стили с использованием .module.scss
- Код отформатирован с помощью расширения Prettier для VSCode (возможно, не весь)
